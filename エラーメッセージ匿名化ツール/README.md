# エラーメッセージ匿名化ツール[cite: 1]

> エラーログに含まれる機密情報を安全に隠すためのブラウザツールです[cite: 1]。ローカルパスや任意の文字列を瞬時に匿名化し、AIへの質問やフォーラムへの投稿に活用できます[cite: 1]。

## 🚀 主な機能 (Features)

* **リアルタイム置換**: 左側のペインにテキストを入力・ペーストするだけで、即座に匿名化されたテキストが右側のペインに生成されます[cite: 1]。
* **カスタム文字列の一括置換**: カンマ区切りで複数の任意の文字列（プロジェクト名や特定のユーザー名など）を指定し、一括で「ユーザー名」に置換可能です[cite: 1]。
* **長い文字列の優先置換**: 部分一致による意図しないテキストの崩れを防ぐため、指定された文字列は文字数の多いものから順に処理されます[cite: 1]。
* **OS標準パスの自動検出**: macOSやLinuxの `/Users/xxx/` や `/home/xxx/`、Windowsの `C:\Users\xxx\` といったパス構造を自動的に検出し、「ユーザー名」に変換します[cite: 1]。
* **ワンクリックコピー**: 変換後のテキストは「結果をコピー」ボタンからワンクリックでクリップボードに保存でき、完了時にはトースト通知が表示されます[cite: 1]。
* **レスポンシブデザイン**: スマートフォンやタブレット端末からでも見やすいよう、画面幅（768px以下）に応じた1カラムレイアウトに自動で切り替わります[cite: 1]。

## 📦 セットアップ・使い方 (Getting Started)

特別なビルド環境やローカルサーバーは必要ありません。

1. 本リポジトリをクローンするか、`index.html` ファイルをダウンロードします。
2. ダウンロードした `index.html` をお好みのWebブラウザ（Chrome, Safari, Edgeなど）で開きます[cite: 1]。
3. 画面上部の設定欄「置換したい文字列」に、隠したいキーワードをカンマ区切りで入力します（任意）[cite: 1]。
4. 左側のテキストエリア（「変換前」）にエラーメッセージを貼り付けます[cite: 1]。
5. 右側のテキストエリア（「変換後」）に匿名化されたテキストが出力されるので、「結果をコピー」ボタンを押して利用してください[cite: 1]。
