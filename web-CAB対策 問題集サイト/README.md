# web-CAB対策 問題集サイト[cite: 5]

> 法則性・命令表・暗号の解き方ガイドと、自己採点式の自作演習バンクを備えた、web-CAB対策用シングルページアプリケーションです。[cite: 5]

## ✨ 主な機能 (Features)

* **解き方ガイド**
  * **法則性**: 移動系や回転系など、頻出6パターンの解説と解く手順を掲載。[cite: 5]
  * **命令表**: 移動・回転・条件付きなどの命令パターンの解説と、ミスの少ない手順を掲載。[cite: 5]
  * **暗号**: 置換型や位置対応型などのパターンと、法則を見つけるコツを解説。[cite: 5]
* **練習問題バンク（自己採点式）**
  * 選択肢をクリックするだけで正誤判定と解説が表示される直感的な演習機能。[cite: 5]
  * カテゴリ（法則性・命令表・暗号）ごとの絞り込み表示に対応。[cite: 5]
* **問題の追加・保存**
  * ユーザー自身で問題文、選択肢、正解、解説をフォームから追加可能。[cite: 5]
  * 追加したデータはブラウザのストレージに保存され、次回以降も利用可能。[cite: 5]
* **サンプル問題の一括読み込み**
  * 各カテゴリ20問、計60問のサンプル問題（法則性・命令表・暗号）をワンクリックでロード可能。[cite: 5]

## 🛠 技術スタック (Tech Stack)

* **HTML5**: セマンティックなマークアップとアクセシビリティを考慮した構造。[cite: 5]
* **CSS3**: カスタムプロパティ（CSS変数）を活用した目に優しい独自のカラーテーマ（インク、ペーパーなど）。[cite: 5]
* **Vanilla JavaScript (ES6+)**: タブ切り替え、問題の動的レンダリング、自己採点ロジック、ストレージへの保存処理を外部ライブラリなしで実装。[cite: 5]

## 🚀 セットアップ・使い方 (Getting Started)

特別な開発環境やサーバーは必要ありません。

1. 本リポジトリをクローンするか、`index.html` ファイルをダウンロードします。
2. ダウンロードした `index.html` をお使いのWebブラウザ（Chrome, Safari, Edgeなど）で開きます。[cite: 5]
3. 画面上部のタブ（「法則性」「命令表」「暗号」）から解き方のコツを学習します。[cite: 5]
4. 「練習問題バンク」タブを開き、「サンプル60問を読み込む」ボタンをクリックして演習を開始してください。[cite: 5]
5. ご自身がお持ちの参考書などの問題を追加したい場合は、「＋ 問題を追加」ボタンから登録できます。[cite: 5]
