# 興学思想4択クイズ

> カテゴリ選択やランダム出題に対応した、シンプルでモダンな4択クイズWebアプリケーションです。JSONファイルから問題を動的に読み込み、学習の定着度を素早くチェックできます。

## ✨ 主な機能（Features）

* **動的な問題読み込み**: 同一階層の `questions.json` から非同期で問題データを取得し、シームレスに出題環境を構築します。


* **柔軟な出題設定**:
* カテゴリ別の絞り込みテスト（複数選択可）に対応しています。


* 出題順を「順番」または「ランダム」から選択可能です。


* 「すべて」のカテゴリを選択している場合は、任意の出題数を指定できます。




* **直感的なクイズUI**:
* A〜Dの選択肢をクリックすると即座に正誤判定（緑色・赤色のハイライト）が行われます。


* 回答後、0.5秒で自動的に次の問題へ遷移するテンポの良い学習体験を提供します。




* **詳細な成績フィードバック**:
* クイズ終了後に全体の正答スコアを表示します。


* 「カテゴリ別正答率」を自動計算し、強みや弱みを可視化します。


* 全問題の「自分の回答」と「正解」を比較できるサマリーリストを出力します。




* **レスポンシブ対応**: CSS Grid / Flexboxを使用し、スマートフォン（380px以下対応）からPCまで画面サイズに合わせてレイアウトが最適化されます。



## 🛠 技術スタック（Tech Stack）

* **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES6+)
* **スタイリング**: 素のCSS（CSS Variables, Media Queries による軽量な設計）
* **通信・処理**: Fetch API, DOM Manipulation, 非同期処理

## 🚀 セットアップ・使い方（Getting Started / Usage）

本アプリは外部ライブラリを必要としませんが、Fetch APIを使用してJSONデータを読み込むため、ローカルサーバー上での実行が必要です。

1. **リポジトリの取得**
```bash
git clone [リポジトリURL]
cd [ディレクトリ名]

```


2. **問題データの準備**
* 同一ディレクトリに `questions.json` を作成・配置します。




3. **ローカルサーバーの起動**
* 例：Pythonがインストールされている場合


```bash
python -m http.server 8000

```


4. **ブラウザでアクセス**
* `http://localhost:8000` を開き、条件を指定して「開始」ボタンをクリックします。

## 📝 Jsonデータ形式の例（参考）

`questions.json` は以下のようなオブジェクトの配列形式で記述してください。

```json
[
  {
    "id": "q1",
    "text": "問題文をここに記述します。",
    "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
    "correctIndex": 0,
    "category": "カテゴリ名"
  }
]

```
