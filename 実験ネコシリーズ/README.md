# 実験ネコシリーズ (Experimental Cats Lab)[cite: 4]

> シュレディンガーの猫からソーンダイクの問題箱まで、学問の世界で語られてきた「猫」の思考実験・逸話を分野横断で集めたアーカイブサイトです[cite: 4]。やわらかいニューモーフィズムのデザインで、科学と猫の不思議な関係を紹介します[cite: 4]。

## 🚀 主な機能 (Features)

* **分野別の記事フィルタリング**: 「物理学」「数学・情報科学」「心理学」などの分野タグをクリックすることで、関連する実験ノートをスムーズに絞り込み表示できます[cite: 4]。
* **ニューモーフィズム・デザイン**: `neu-flat`, `neu-pressed`, `neu-concave` などのCSSクラスを活用し、要素が浮き出たり沈み込んだりする、立体的で触り心地の良さそうなUIを実現しています[cite: 4]。
* **ダークモード / ライトモード切替**: ヘッダーに配置された「肉球トグルボタン（paw-toggle）」により、閲覧環境に合わせてサイトのカラーテーマを切り替えることができます[cite: 4]。
* **学術的なコンテンツの網羅**: 量子力学の重ね合わせから、試行錯誤学習、ネコひねり問題まで、多彩な学術分野の思考実験をカード形式で直感的に探すことができます[cite: 4]。

---

## 🛠 技術スタック (Tech Stack)

* **HTML5**: セマンティックな構造化と、`aria-label` などのアクセシビリティを意識したマークアップ[cite: 4]。
* **CSS3**: カスタムプロパティ（CSS変数）を利用したニューモーフィズムデザイン（`style.css` として分離）[cite: 4]。
* **Vanilla JavaScript**: ダークモードのテーマ切り替えや、データ属性（`data-filter`）を利用した記事フィルタリング機能のDOM操作（`script.js` として分離）[cite: 4]。

## 📦 セットアップ・使い方 (Getting Started)

特別なビルド環境やローカルサーバーは必要ありません。以下の手順ですぐに確認できます。

1. 本リポジトリをクローンするか、ZIP形式でダウンロードします。
2. ダウンロードしたフォルダを展開します。
3. フォルダ内の `index.html` をお好みのWebブラウザ（Chrome, Safari, Edgeなど）で開きます[cite: 4]。
4. （開発者向け）VSCodeなどのエディタで開き、「Live Server」等の拡張機能を使用すると、スタイルやスクリプトの変更が即座に反映され、より快適に編集できます。
