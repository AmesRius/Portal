# デマ耐性診断 (Fake News Immunity Test)

> SNS風のタイムラインを流れる投稿に対し、あなたがどう反応するかをテストする体験型リテラシー診断ツールです。フェイクニュースに対する「拡散リスク」や「慎重さ」を測定し、あなたの情報行動を6つのタイプに分類します。

---

## ✨ 主な機能 (Features)

* **実践的なSNSシミュレーション**: 「いいね」「拡散」「検証」「通報」など、実際のSNSに近いアクションボタンを通じて直感的に診断を進めることができます。
* **ランダムな出題システム**: 用意された多様なジャンル（健康、災害、政治、生活、科学など）のプールから、毎回15問がランダムに出題されるため、何度でも楽しめます。
* **高度な行動分析**: ユーザーのリアクション傾向を「拡散スコア」「検証スコア」「感情への反応」「バイアス傾向」の4軸で評価し、レーダーチャートとして美しく可視化します。
* **6つの診断タイプ**: 行動履歴をもとに、「拡散反射型」から「慎重検証型」「選択的拡散型」など、6つのユニークなタイプに分類し、具体的なアドバイスを提供します。
* **答え合わせと解説**: 診断終了後、自分が反応した情報の真偽（デマ・事実）とその理由、情報の騙しのテクニック（文脈切り取り、権威詐称など）を振り返ることができます。
* **ワンクリック画像シェア**: 診断結果を魅力的なカードデザインの画像として即座に生成・保存し、SNSで簡単にシェアできます。

## 🛠 技術スタック (Tech Stack)

* **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES6+)
* **フォント**: Google Fonts (`Zen Maru Gothic`, `Noto Sans JP`) による親しみやすいタイポグラフィ
* **ライブラリ**: 
  * [html2canvas](https://html2canvas.hertzen.com/) - 結果画面の画像生成に使用
* **依存関係**: ビルドツール不要。単一のHTMLファイルにスタイルとロジックが統合された軽量設計です。

## 🚀 セットアップ・使い方 (Getting Started / Usage)

特別なサーバー構築やモジュールのインストールは不要です。

1. 本リポジトリをクローンするか、`index.html` ファイルをダウンロードします。
2. ダウンロードした `index.html` をお好みのWebブラウザ（Chrome, Safari, Firefox, Edgeなど）で開きます。
3. 最初の画面で「診断をはじめる」をクリックし、タイムラインに流れる投稿に対して自由にアクション（またはスルー）して進めてください。

*(開発者向け)*
コードを修正してリアルタイムでプレビューしたい場合は、VS Codeの「Live Server」拡張機能などのローカルサーバーを使用することをおすすめします。投稿データは `POSTS_POOL` 配列を編集することで、容易に問題の追加やカスタマイズが可能です。
